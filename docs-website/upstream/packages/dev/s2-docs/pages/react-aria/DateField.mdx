## Value

Use the `value` or `defaultValue` prop to set the date value, using objects in the [@internationalized/date](internationalized/date/) package. This library supports parsing date strings in multiple formats, manipulation across international calendar systems, time zones, etc.

```tsx nativeModule="DateField/solid-example-3.tsx" solid="DateField/solid-example-3.tsx"  files={["packages/dev/s2-docs/pages/react-aria/DateField/solid-example-3.tsx"]}
import {parseDate, getLocalTimeZone, type CalendarDate} from '@internationalized/date';
import {useDateFormatter} from '../../../../../../../packages/react-aria/src/i18n/useDateFormatter';
import {DateField} from './DateField/vanilla/DateField.solid';
import {createSignal} from 'solid-js';
function Example() {
  let [date, setDate] = createSignal<CalendarDate | null>(parseDate('2020-02-03'));
  let formatter = useDateFormatter({ dateStyle: 'full' });

  return (
    <>
      <DateField
        ///- begin highlight -///
        value={date()}
        onChange={setDate} />
      {/*- end highlight -*/}
      <p>Selected date: {date() ? formatter().format(date()!.toDate(getLocalTimeZone())) : '--'}</p>
    </>
  );
}
```

### Format options

The date format is automatically determined based on the user's locale. `DateField` supports several props to control how values are displayed.

```tsx nativeModule="DateField/solid-example-4.tsx" solid="DateField/solid-example-4.tsx" docs={docs.exports.DateField} links={docs.links} props={['granularity', 'hourCycle', 'hideTimeZone', 'shouldForceLeadingZeros']} initialProps={{label: 'Date'}} files={["packages/dev/s2-docs/pages/react-aria/DateField/solid-example-4.tsx"]}
import {parseZonedDateTime} from '@internationalized/date';
import {DateField} from './DateField/vanilla/DateField.solid';
<DateField
  {...props} /* PROPS */
  defaultValue={parseZonedDateTime('2025-02-03T08:45:00[America/Los_Angeles]')} />
```

### International calendars

By default, `DateField` displays the value using the calendar system for the user's locale. Use `<I18nProvider>` to override the calendar system by setting the [Unicode calendar locale extension](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Locale/calendar#adding_a_calendar_in_the_locale_string). The `onChange` event always receives a date in the same calendar as the `value` or `defaultValue` (Gregorian if no value is provided), regardless of the displayed locale.

```tsx nativeModule="DateField/solid-example-5.tsx" solid="DateField/solid-example-5.tsx" wide docs={docs.exports.I18nProvider} links={docs.links} props={['locale']} initialProps={{locale: 'hi-IN-u-ca-indian'}} files={["packages/dev/s2-docs/pages/react-aria/DateField/solid-example-5.tsx"]}
import {I18nProvider} from 'solid-aria-components';
import {parseZonedDateTime} from '@internationalized/date';
import {DateField} from './DateField/vanilla/DateField.solid';
<I18nProvider {...props}/* PROPS */>
  <DateField defaultValue={parseZonedDateTime('2025-02-03T08:45:00[America/Los_Angeles]')} />
</I18nProvider>
```

## Forms

Use the `name` prop to submit the selected date to the server as an [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) string. Set the `isRequired`, `minValue`, or `maxValue` props to validate the value, or implement custom client or server-side validation. See the [Forms](forms) guide to learn more.

```tsx nativeModule="DateField/solid-example-6.tsx" solid="DateField/solid-example-6.tsx"  files={["packages/dev/s2-docs/pages/react-aria/DateField/solid-example-6.tsx"]}
import {today, getLocalTimeZone} from '@internationalized/date';
import {DateField} from './DateField/vanilla/DateField.solid';
import {Button} from './DateField/vanilla/Button.solid';
import {Form} from './DateField/vanilla/Form.solid';;
<Form>
  <DateField
    label="Appointment date"
    ///- begin highlight -///
    name="date"
    isRequired
    minValue={today(getLocalTimeZone())}
    ///- end highlight -///
  />
  <Button type="submit">Submit</Button>
</Form>
```
