## Custom trigger

`DialogTrigger` works with any pressable React Aria component (e.g. [Button](Button), [Link](Link), etc.). Use the `<Pressable>` component or [usePress](usePress) hook to wrap a custom trigger element such as a third party component or DOM element.

```tsx  nativeModule="Popover/solid-demo03.tsx"
import type {JSX} from '@solidjs/web';
import {Pressable, DialogTrigger} from 'solid-aria-components/Popover';
import {Popover} from './ListBox/native/vanilla/solid-Popover';

<DialogTrigger>
  {/*- begin highlight -*/}
  <Pressable>
    {forwardedProps => (<span {...forwardedProps} ref={forwardedProps.ref as JSX.Ref<HTMLSpanElement>} tabindex={forwardedProps.tabIndex} role="button">Custom trigger</span>)}
  </Pressable>
  {/*- end highlight -*/}
  <Popover style={{padding: "16px"}}>
    This popover was triggered by a custom button.
  </Popover>
</DialogTrigger>
```

<InlineAlert variant="notice">
  <Heading>Accessibility</Heading>
  <Content>Any `<Pressable>` child must have an [interactive ARIA role](https://www.w3.org/TR/wai-aria-1.2/#widget_roles) or use an appropriate semantic HTML element so that screen readers can announce the trigger. Trigger components must forward their `ref` and spread all props to a DOM element.</Content>
</InlineAlert>

## Custom anchor

To position a popover relative to a different element than its trigger, use the `triggerRef` and `isOpen` props instead of `<DialogTrigger>`. `onOpenChange` will be called when the user closes the popover.

```tsx  nativeModule="Popover/solid-demo04.tsx"
import {createSignal} from 'solid-js';
import {createSignal as createRefSignal} from 'solid-js';
import {Popover} from './ListBox/native/vanilla/solid-Popover';
import {Button} from './ListBox/native/vanilla/solid-Button';

function Example() {
  let [isOpen, setOpen] = createSignal(false);
  let [triggerElement, setTriggerElement] = createRefSignal<HTMLSpanElement | null>(null);
  let triggerRef = {get current() { return triggerElement(); }};

  return (
    <div>
      <Button onPress={() => setOpen(true)}>Trigger</Button>
      <span ref={setTriggerElement} style={{"padding-left": "12px"}}>Popover will be positioned relative to me</span>
      <Popover
        style={{padding: "16px"}}
        /*- begin highlight -*/
        triggerRef={triggerRef}
        isOpen={isOpen()}
        onOpenChange={setOpen}>
        {/*- end highlight -*/}
        I'm over here!
      </Popover>
    </div>
  );
}
```
