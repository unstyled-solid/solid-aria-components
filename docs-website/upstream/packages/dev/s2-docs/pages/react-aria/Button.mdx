## Events

Use the `onPress` prop to handle interactions via mouse, keyboard, and touch. This is similar to `onClick`, but normalized for consistency across browsers, devices, and interaction methods. Read our [blog post](blog/building-a-button-part-1) to learn more.

The `onPressStart`, `onPressEnd`, and `onPressChange` events are also emitted as the user interacts with the button. Each of these handlers receives a <TypeLink links={typesDocs.links} type={typesDocs.exports.PressEvent} />, which provides information about the target and interaction method. See [usePress](usePress) for more details.

```tsx render solid="./Button/solid-events.tsx"
"use client";
import {Button} from './Button/vanilla/Button.solid';
import {createSignal} from 'solid-js';

function Example() {
  let [pointerType, setPointerType] = createSignal('');

  return (
    <>
      <Button
        /*- begin highlight -*/
        onPressStart={e => setPointerType(e.pointerType)}
        onPressEnd={() => setPointerType('')}>
        {/*- end highlight -*/}
        Press me
      </Button>
      <p>{pointerType() ? `You are pressing the button with a ${pointerType()}!` : 'Ready to be pressed.'}</p>
    </>
  );
}
```

## Pending

Use the `isPending` prop to display a pending state. Pending buttons remain focusable, but are otherwise disabled. Pending state changes are announced to assistive technologies.

```tsx render solid="./Button/solid-pending.tsx"
"use client";
import {Button} from './Button/vanilla/Button.solid';
import {createSignal, onCleanup} from 'solid-js';

function PendingButton() {
  let [isPending, setPending] = createSignal(false);
  let timer: ReturnType<typeof setTimeout> | undefined;
  onCleanup(() => clearTimeout(timer));

  return (
    <Button
      ///- begin highlight -///
      isPending={isPending()}
      ///- end highlight -///
      onPress={() => {
        setPending(true);
        timer = setTimeout(() => {
          setPending(false);
        }, 5000);
      }}>
      Save
    </Button>
  );
}
```

## Link buttons

The `Button` component always represents a button semantically. To create a link that visually looks like a button, use the [Link](Link) component instead. You can reuse the same styles you apply to the `Button` component on the `Link`.

```tsx render solid="./Button/solid-link.tsx"
"use client";
import {Link} from 'solid-aria-components';

<Link className="react-aria-Button button-base" href="https://adobe.com/" target="_blank">
  Adobe
</Link>
```
