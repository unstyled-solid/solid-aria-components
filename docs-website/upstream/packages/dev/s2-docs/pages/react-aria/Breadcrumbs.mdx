## Content

`Breadcrumbs` follows the [Collection Components API](collections?component=Breadcrumbs), accepting both static and dynamic collections. This example shows a dynamic collection, passing a list of objects to the `items` prop, and a function to render the children. The `onAction` event is called when a user presses a breadcrumb.

```tsx  nativeModule="Breadcrumbs/solid-example-3.tsx" solid="Breadcrumbs/solid-example-3.tsx"
import type { Key } from 'solid-aria-components';
import { Breadcrumbs, Breadcrumb } from './Tabs/vanilla/Breadcrumbs';
import { createSignal } from 'solid-js';
function Example(props: Record<string, unknown>) {
  let [breadcrumbs, setBreadcrumbs] = createSignal([{
    id: 1,
    label: 'Home'
  }, {
    id: 2,
    label: 'Trendy'
  }, {
    id: 3,
    label: 'March 2022 Assets'
  }]);
  let navigate = (id: Key) => {
    let i = breadcrumbs().findIndex(item => item.id === id);
    setBreadcrumbs(breadcrumbs().slice(0, i + 1));
  };
  return /*- begin highlight -*/<Breadcrumbs items={breadcrumbs()} onAction={navigate}>
      {item => <Breadcrumb>{item.label}</Breadcrumb>}
    </Breadcrumbs>
  /*- end highlight -*/;
}
```

Landmarks help assistive technology users quickly find major sections of a page. Place breadcrumbs inside a `<nav>` element with an `aria-label` to create a navigation landmark.</Content>
