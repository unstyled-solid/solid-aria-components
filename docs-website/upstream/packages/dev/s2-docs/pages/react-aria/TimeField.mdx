## Value

Use the `value` or `defaultValue` prop to set the time value, using objects in the [@internationalized/date](internationalized/date/) package. `TimeField` accepts plain [Time](internationalized/date/Time), [CalendarDateTime](internationalized/date/CalendarDateTime), or [ZonedDateTime](internationalized/date/ZonedDateTime), but only displays the time.

```tsx nativeModule="TimeField/solid-example-3.tsx" solid="TimeField/solid-example-3.tsx"  files={["packages/dev/s2-docs/pages/react-aria/TimeField/solid-example-3.tsx"]}
import {Time} from '@internationalized/date';
import {TimeField} from './TimeField/vanilla/TimeField.solid';
import {createSignal} from 'solid-js';
function Example() {
  let [time, setTime] = createSignal<Time | null>(new Time(11, 45));

  return (
    <>
      <TimeField
        ///- begin highlight -///
        value={time()}
        onChange={setTime} />
      {/*- end highlight -*/}
      <p>Selected time: {time() ? time()!.toString() : '--'}</p>
    </>
  );
}
```

### Format options

The time format is automatically determined based on the user's locale. `TimeField` supports several props to control how values are displayed.

```tsx nativeModule="TimeField/solid-example-4.tsx" solid="TimeField/solid-example-4.tsx" docs={docs.exports.TimeField} links={docs.links} props={['granularity', 'hourCycle', 'hideTimeZone', 'shouldForceLeadingZeros']} initialProps={{label: 'Time'}} files={["packages/dev/s2-docs/pages/react-aria/TimeField/solid-example-4.tsx"]}
import {parseZonedDateTime} from '@internationalized/date';
import {TimeField} from './TimeField/vanilla/TimeField.solid';
<TimeField
  {...props} /* PROPS */
  defaultValue={parseZonedDateTime('2025-02-03T17:45:00[America/Los_Angeles]')} />
```

## Forms

Use the `name` prop to submit the selected date to the server as an [ISO 8601](https://en.wikipedia.org/wiki/ISO_8601) string. Set the `isRequired`, `minValue`, or `maxValue` props to validate the value, or implement custom client or server-side validation. See the [Forms](forms) guide to learn more.

```tsx nativeModule="TimeField/solid-example-5.tsx" solid="TimeField/solid-example-5.tsx"  files={["packages/dev/s2-docs/pages/react-aria/TimeField/solid-example-5.tsx"]}
import {Time} from '@internationalized/date';
import {TimeField} from './TimeField/vanilla/TimeField.solid';
import {Button} from './TimeField/vanilla/Button.solid';
import {Form} from './TimeField/vanilla/Form.solid';;
<Form>
  <TimeField
    label="Appointment time"
    ///- begin highlight -///
    name="time"
    isRequired
    minValue={new Time(9)}
    maxValue={new Time(17)}
    validate={time => time?.minute % 15 !== 0 ? 'Appointments start every 15 minutes.' : null}
    ///- end highlight -///
  />
  <Button type="submit">Submit</Button>
</Form>
```
