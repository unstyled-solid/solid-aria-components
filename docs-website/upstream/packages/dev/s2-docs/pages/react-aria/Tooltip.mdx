## Interactions

Tooltips appear after a "warmup" delay when hovering, or instantly on focus. Once a tooltip is displayed, other tooltips display immediately. If the user waits for the "cooldown period" before hovering another element, the warmup timer restarts.

```tsx  docs={docs.exports.TooltipTrigger} links={docs.links} props={['trigger', 'delay', 'closeDelay', 'isDisabled', 'shouldCloseOnPress']} type="vanilla" nativeModule="Tooltip/solid-demo03.tsx"
import {TooltipTrigger} from 'solid-aria-components/Tooltip';
import {Tooltip} from './ListBox/native/vanilla/solid-Tooltip';
import {Button} from './ListBox/native/vanilla/solid-Button';
import {Edit} from './../ListBox/native-icons/solid-icons';
import {Save} from './../ListBox/native-icons/solid-icons';

function Example(props: Record<string, unknown>) {
  return (
    <div style={{display: 'flex', gap: "8px"}}>
      {/*- begin highlight -*/}
      <TooltipTrigger {...props}{...props}>
      {/*- end highlight -*/}
        <Button aria-label="Edit">
          <Edit size={18} />
        </Button>
        <Tooltip>
          Edit
        </Tooltip>
      </TooltipTrigger>
      <TooltipTrigger {...props}{...props}>
        <Button aria-label="Save">
          <Save size={18} />
        </Button>
        <Tooltip>
          Save
        </Tooltip>
      </TooltipTrigger>
    </div>
  );
}
```

## Custom trigger

`TooltipTrigger` works with any focusable React Aria component (e.g. [Button](Button), [Link](Link), etc.). Use the `<Focusable>` component to wrap a custom trigger element such as a third party component or DOM element.

```tsx  nativeModule="Tooltip/solid-demo04.tsx"
import {Focusable, TooltipTrigger} from 'solid-aria-components/Tooltip';
import {Tooltip} from './ListBox/native/vanilla/solid-Tooltip';

<TooltipTrigger>
  {/*- begin highlight -*/}
  <Focusable>
    {forwardedProps => (<span {...forwardedProps} role="button">Custom trigger</span>)}
  </Focusable>
  {/*- end highlight -*/}
  <Tooltip>Tooltip</Tooltip>
</TooltipTrigger>
```

<InlineAlert variant="notice">
  <Heading>Accessibility</Heading>
  <Content>Any `<Focusable>` child must have an ARIA role or use an appropriate semantic HTML element so that screen readers can announce the tooltip. Trigger components must forward their `ref` and spread all props to a DOM element.</Content>
</InlineAlert>

```tsx
function CustomTrigger(props) {
  return <button {...props} />;
}
```

[DialogTrigger](Modal#custom-trigger) or [MenuTrigger](Menu#custom-trigger) with a `<Pressable>` trigger also works with `TooltipTrigger`. All `<Pressable>` elements are already focusable, so there's no need to wrap them in `<Focusable>`.
